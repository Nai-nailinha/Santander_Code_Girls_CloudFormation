# ☁️ AWS CloudFormation — Criando sua Primeira Stack  

## 📘 Descrição
Este projeto faz parte do **Bootcamp Santander Code Girls | AWS Cloud Practitioner**, com o objetivo de **implementar a primeira Stack usando AWS CloudFormation**, consolidando os conceitos de *Infrastructure as Code (IaC)*.  

Durante a prática, foram criados e configurados recursos na AWS de forma automatizada, explorando como o CloudFormation ajuda a padronizar, documentar e escalar implantações na nuvem.


## 🎯 Objetivos de Aprendizagem
- Aplicar os conceitos de *Infrastructure as Code* na AWS.  
- Criar e gerenciar **stacks** utilizando CloudFormation.  
- Documentar processos técnicos de forma clara e reprodutível.  
- Utilizar o GitHub como ferramenta para compartilhamento e versionamento.  


## ⚙️ O que foi feito
Durante o desafio, foram realizados:
- Criação de um **template CloudFormation** (em YAML) com recursos como **Bucket S3 e Role IAM**.  
- Deploy e validação da stack pelo **Console da AWS**.  
- Testes de atualização e exclusão automatizada da infraestrutura.  
- Registro das lições aprendidas e prints do processo.  

## 💡 Principais Aprendizados
- Como o CloudFormation simplifica a criação de ambientes complexos com poucos comandos.  
- Diferença entre **template**, **stack** e **recursos**.  
- Importância do IaC para automação, consistência e governança em nuvem.  
- O valor da documentação e versionamento em times de sustentação e cloud.
